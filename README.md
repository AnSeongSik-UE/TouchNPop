AR 두더지 잡기

- Google ARCore를 활용하여 실제 공간 인식 기반 AR 캐릭터 배치 기능 구현
- 안정적으로 캐릭터가 생성될 수 있도록 AR Plane Detection 기반의 Object Plane 생성 기능 구현
- 화면에서 임의의 좌표를 선택해 해당 지점이 Object Plane일 경우 캐릭터를 자동 생성하는 로직 개발
- 생성된 캐릭터는 15가지 애니메이션 중 무작위로 1개 행동을 실행하도록 설계
- Player가 캐릭터를 터치하면 점수를 1점 획득하도록 터치 이벤트 처리
- 60초 타이머 기반 게임 종료 처리
- SaveGame을 활용하여 최고점을 기기에 저장
